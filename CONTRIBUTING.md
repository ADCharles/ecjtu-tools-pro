# 贡献 / Contributing

提交问题时，请说明所用包、Dart或Flutter版本、操作系统、复现步骤和预期行为。示例数据使用合成内容，并移除账号、凭据、个人资料和私人文件。

修改计算逻辑时说明公式来源、单位及输入条件；修改公共接口时同步更新使用示例和相应测试。

你有意提交到本项目的自有代码贡献，按GPLv3（仅第3版）及`LICENSE-ADDITIONAL.md`中的署名条款和附加许可提供。保留已有版权与第三方声明，并只提交你有权按这些条件提供的内容。

When reporting an issue, include the package, Dart or Flutter version, operating system, reproduction steps and expected behavior. Use synthetic examples and remove accounts, credentials, personal information and private files.

For calculation changes, document the formula source, units and input assumptions. Update examples and relevant tests when changing public interfaces.

Original code intentionally submitted for inclusion is contributed under GPLv3-only and the attribution term and additional permission in `LICENSE-ADDITIONAL.md`. Preserve existing copyright and third-party notices, and contribute only material you are entitled to provide under these terms.
